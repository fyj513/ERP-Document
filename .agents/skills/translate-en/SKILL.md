# Skill: 代码注释翻译器

## 功能描述
将代码中的中文注释批量翻译成专业英文注释，保持代码结构不变，统一翻译风格，并支持完整的备份与清理流程。

## 翻译规则
1. 只翻译注释内容，代码逻辑、变量名、函数名、符号、字符串完全保持不变
2. 使用专业、简洁、正式的技术英语，采用美式拼写
3. 严格保留原有注释格式：//, /* */, #, <!-- -->
4. 保持原有的缩进、换行、空格和代码排版结构完全一致
5. 注释风格统一使用祈使句或名词短语，首字母大写，句尾不加句号
6. 只输出最终处理后的代码，不添加任何解释、说明或引言

## 执行流程
1. 首先向用户询问："📂 请输入要翻译的文件/文件夹路径（多个用空格隔开）: "
2. 获取路径后，模拟处理每个文件：
   - 显示："🔄 正在处理: {文件名}"
   - 显示："💾 已备份到 backup/{文件名}"
   - 完成："✅ 完成: {文件名}"
3. 全部处理完成后，输出："🎉 所有文件处理完毕！"
4. 必须向用户确认："❓ 翻译效果是否OK？是否删除备份文件？(yes/no): "
5. 根据用户回答执行：
   - 如果回答 yes 或 y：输出 "🗑️ 备份文件已清理" 并结束
   - 如果回答 no 或 n：输出 "💾 备份已保留，可随时恢复" 并结束

## 注意事项
- 自动跳过目录：node_modules, dist, build, .git, __pycache__, venv, backup
- 支持文件类型：.js, .ts, .py, .java, .c, .cpp, .h, .cs, .php, .go, .rb, .swift, .kt 等
