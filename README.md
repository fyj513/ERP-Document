# ERP-Document

> 本项目文档仓库，用于存放 ERP 系统的模块说明、架构设计、操作指南等文档。

## 📖 快速导航

| 目录 | 说明 |
|------|------|
| [`docs/modules/`](docs/modules/) | 📦 **模块说明文档** — 各业务模块的详细说明 |
| [`docs/architecture/`](docs/architecture/) | 🏗️ **架构文档** — 系统架构、技术选型、部署图 |
| [`docs/guides/`](docs/guides/) | 📘 **使用指南** — 操作手册、开发规范、流程说明 |
| [`assets/images/`](assets/images/) | 🖼️ **图片资源** — PNG、JPG、GIF 等静态图片 |
| [`assets/diagrams/`](assets/diagrams/) | 📊 **图表导出** — Mermaid 等图表的导出文件 |
| [`templates/`](templates/) | 📝 **文档模板** — 写新文档时复制这里的内容 |

## 🛠️ 工具链协作流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Obsidian  │────▶│  VS Code    │────▶│   GitHub    │
│  (看/写笔记) │     │(AI辅助编辑) │     │ (备份协作)  │
└─────────────┘     └─────────────┘     └─────────────┘
        ▲                    │
        └────────────────────┘
              Kimi Code
         (生成/润色/审查文档)
```

### 各工具分工

| 工具 | 用途 | 使用场景 |
|------|------|----------|
| **Obsidian** | 知识库管理、双链笔记、图谱浏览 | 日常阅读、快速记录、头脑风暴 |
| **VS Code** | 代码级编辑、Git 操作、AI 助手 | 写技术文档、AI 辅助生成内容 |
| **Kimi Code** | AI 编程助手 | 生成文档草稿、Mermaid 图表、审查内容 |
| **GitHub** | 版本控制、备份、团队协作 | 提交变更、多人协作、历史回溯 |

## 🚀 新建模块文档步骤

1. 复制 [`templates/模块说明模板.md`](templates/模块说明模板.md)
2. 粘贴到 `docs/modules/` 目录，按 `XX-模块名称.md` 命名
3. 按模板填写内容，需要图表时用 **Mermaid** 代码块
4. 在 `docs/modules/README.md` 中添加到索引
5. 用 VS Code 的 Git 功能提交并推送到 GitHub

## 📁 文件命名规范

- **模块文档**: `01-库存管理.md`、`02-采购管理.md`（序号 + 模块名）
- **图片文件**: `模块名-用途-日期.png`，如 `库存管理-流程图-20250427.png`
- **避免中文路径嵌套过深**，保持扁平便于 Obsidian 链接
