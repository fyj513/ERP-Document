## 时间日期库使用说明书
### 1.使用前准备（初始化配置）

**什么时候做：** 项目启动时做一次，通常放在入口文件里。

  ```
    import { initDateTimeConfig } from '@pram3/datetime';

// 初始化时间日期库的配置
initDateTimeConfig({
  // 公司默认配置（管理员在后台设置）
  company: {
    timezone: 'Asia/Shanghai',    // 时区：中国用 'Asia/Shanghai'
    locale: 'zh-CN',               // 语言：中文
    dateFormat: '%Y-%m-%d',        // 日期格式：2024-01-15
    timeFormat: '%H:%M:%S',        // 时间格式：14:30:00
    use24Hour: true,               // 使用24小时制
  },
  
  // 用户个人设置（用户自己在设置页修改）
  user: {
    // 如果用户没改，就用公司的默认
    // 如果用户改了，这里覆盖公司配置
  }
});

  ```
  **参数说明：**

| 参数                   | 类型  | 必填  | 说明                       |     |
| -------------------- | --- | --- | ------------------------ | --- |
| `company`            | 对象  | 否   | 公司默认配置                   |     |
| `company.timezone`   | 字符串 | 否   | 时区，如 `'Asia/Shanghai'`   |     |
| `company.locale`     | 字符串 | 否   | 语言，如 `'zh-CN'`、`'en-US'` |     |
| `company.dateFormat` | 字符串 | 否   | 日期格式                     |     |
| `company.timeFormat` | 字符串 | 否   | 时间格式                     |     |
| `company.use24Hour`  | 布尔  | 否   | 是否24小时制                  |     |
| `user`               | 对象  | 否   | 用户个人配置（优先级高于公司）          |     |
### 2.DateTimeObj —— 日期时间对象
#### 2.1 创建日期时间对象
**场景：拿到一个时间戳，要显示给用户看**
```
import { DateTimeObj } from '@pram3/datetime';

// 方式1：获取当前时间
const now = DateTimeObj.now();

// 方式2：从数据库拿到的时间戳（UTC毫秒）
const timestamp = 1705312800000;  // 数据库里存的
const orderDate = DateTimeObj.fromUTCTimestamp(timestamp);

// 方式3：从用户输入的字符串解析
const userInput = '2024-01-15 14:30:00';
const meetingTime = DateTimeObj.fromString(userInput);

// 方式4：从字符串+指定格式解析
const customInput = '15/01/2024';
const date = DateTimeObj.fromString(customInput, '%d/%m/%Y');
```
**参数说明：**

| 方法                                        | 参数                          | 返回值                    | 说明      |
| ----------------------------------------- | --------------------------- | ---------------------- | ------- |
| `DateTimeObj.now()`                       | 无                           | `DateTimeObj`          | 当前时间    |
| `DateTimeObj.fromUTCTimestamp(timestamp)` | `timestamp`: 数字（毫秒）         | `DateTimeObj`          | 从时间戳创建  |
| `DateTimeObj.fromString(value)`           | `value`: 字符串                | `DateTimeObj` 或 `null` | 自动检测格式  |
| `DateTimeObj.fromString(value, format)`   | `value`: 字符串`format`: 格式字符串 | `DateTimeObj` 或 `null` | 按指定格式解析 |

> ⚠️ **注意**：`fromString` 可能返回 `null`（用户输入错误时），要用 `?.` 或判断
#### 2.2 格式化显示
**场景：把时间显示在页面上**
```
const date = DateTimeObj.fromUTCTimestamp(1705312800000);

// 自定义格式
console.log(date.format('%Y-%m-%d'));        // "2024-01-15"
console.log(date.format('%Y年%m月%d日'));     // "2024年01月15日"
console.log(date.format('%H:%M:%S'));        // "14:30:00"

// 快捷属性（常用，推荐）
console.log(date.htmlDate);      // "2024-01-15" （用于HTML input）
console.log(date.localDate);     // "2024-01-15" （本地化的日期）
console.log(date.localTime);     // "14:30:00" （本地化的时间）
console.log(date.localDateTime); // "2024-01-15 14:30:00"

// 相对时间（人性化显示）
console.log(date.rel.toString());  // "3天前"、"刚刚"、"2小时后"
```

**format 支持的占位符：**

|占位符|输出示例|说明|
|---|---|---|
|`%Y`|`2024`|完整年份|
|`%m`|`01`|月份（补零）|
|`%d`|`15`|日期（补零）|
|`%H`|`14`|小时（24小时制）|
|`%I`|`02`|小时（12小时制）|
|`%M`|`30`|分钟|
|`%S`|`00`|秒|
|`%p`|`PM`|AM/PM|
|`%a`|`Mon`|星期缩写|
|`%A`|`Monday`|星期全称|
#### 2.3 判断属性
**场景：根据日期做不同处理**

```
const date = DateTimeObj.now(); 
// 判断是否是周末 
if (date.isWeekend) {   
console.log('周末愉快！'); 
} 
// 判断是否是工作日 
if (date.isWeekday) 
{   
console.log('该上班了...'); 
}
```

#### 2.4 日期计算

**场景：计算7天后、3小时前**
```
const now = DateTimeObj.now();

// 7天后
const nextWeek = now.addDays(7);
console.log(nextWeek.format('%Y-%m-%d'));

// 3小时后
const later = now.addHours(3);

// 30分钟后
const soon = now.addMinutes(30);
```

---

#### 2.5 日期比较

**场景：判断哪个日期在前、是否过期**

```
const date1 = DateTimeObj.fromString('2024-01-15');
const date2 = DateTimeObj.fromString('2024-01-20');

// 比较
date1.isBefore(date2);   // true（date1 在 date2 之前）
date1.isAfter(date2);    // false
date1.equals(date2);     // false

// 计算差值（毫秒）
const diff = date2.diff(date1);  // 432000000（5天的毫秒数）
```

### 3.TimeObj —— 纯时间对象（无日期）

#### 3.1 什么时候用？

> **通俗解释**：
> DateTimeObj 是"2024年1月15日下午3点"（具体某一天）；
> TimeObj 是"每天下午3点"（重复的、不指定哪天）。

**场景：**

- 每天定时提醒
- 每周会议时间
- 营业时间（每天9:00-18:00）

---

#### 3.2 创建时间对象

```
import { TimeObj } from '@pram3/datetime';

// 方式1：从字符串解析（自动检测格式）
const lunchTime = TimeObj.fromString('12:00');      // 12:00
const meetingTime = TimeObj.fromString('14:30');    // 14:30
const amTime = TimeObj.fromString('08:00 AM');      // 08:00
const pmTime = TimeObj.fromString('02:30 PM');      // 14:30
const numericTime = TimeObj.fromString('1430');     // 14:30

// 方式2：指定小时和分钟
const startTime = TimeObj.fromHoursMinutes(9, 0);   // 09:00

// 方式3：指定是否全球统一时间
const reminder = TimeObj.fromString('12:00', false);   // 每天12点（本地时间）
const meeting = TimeObj.fromString('15:00', true);     // 15:00 UTC（全球同时）
```

**参数说明：**

|方法|参数|返回值|说明|
|---|---|---|---|
|`TimeObj.fromString(value)`|`value`: 字符串|`TimeObj` 或 `null`|自动检测格式|
|`TimeObj.fromString(value, sameTimeGlobally)`|`value`: 字符串<br>`sameTimeGlobally`: 布尔|`TimeObj` 或 `null`|指定时区行为|
|`TimeObj.fromHoursMinutes(hours, minutes)`|`hours`: 0-23<br>`minutes`: 0-59|`TimeObj` 或 `null`|从数字创建|

**支持的输入格式：**

|输入|结果|说明|
|---|---|---|
|`"800"`|08:00|短数字|
|`"0800"`|08:00|数字|
|`"08:00"`|08:00|24小时制|
|`"08:00 AM"`|08:00|12小时制上午|
|`"02:30 PM"`|14:30|12小时制下午|
|`"2145"`|21:45|数字（下午）|

---

#### 3.3 格式化显示
```
const time = TimeObj.fromHoursMinutes(14, 30);

// 格式化
console.log(time.format('%H:%M:%S'));  // "14:30:00"

// 快捷属性
console.log(time.localTime);  // "14:30:00"

// 获取各个部分
console.log(time.hours);        // 14
console.log(time.minutes);      // 30
console.log(time.seconds);      // 0
```

---

#### 3.4 时区处理（重点！）

**场景：跨国会议，各地显示当地时间，但同时开始**

```
// 创建一个全球统一的时间（UTC 15:00）
const meetingTime = TimeObj.fromString('15:00', true);

// 各地显示的时间
console.log(meetingTime.GMT(0));    // "15:00:00" （伦敦）
console.log(meetingTime.GMT(8));    // "23:00:00" （北京，+8小时）
console.log(meetingTime.GMT(-5));   // "10:00:00" （纽约，-5小时）
console.log(meetingTime.GMT('+08:00'));  // 字符串格式也可以
```
**场景：每天固定时间（不随时区变化）**

```
// 每天中午12点吃饭提醒（不管在哪都是12点）
const lunchReminder = TimeObj.fromString('12:00', false);

// 不管传什么时区，都显示12:00
console.log(lunchReminder.GMT(8));   // "12:00:00"
console.log(lunchReminder.GMT(-5));  // "12:00:00"
```
**`sameTimeGlobally` 的区别：**

|值|含义|例子|
|---|---|---|
|`true`|全球统一时刻|会议、直播、比赛|
|`false`|本地固定时间|吃饭提醒、睡觉提醒、营业时间|

### 4.完整示例：一个订单页面

```
import { DateTimeObj, TimeObj, initDateTimeConfig } from '@pram3/datetime';

// ========== 1. 初始化（项目启动时做一次）==========
initDateTimeConfig({
  company: {
    timezone: 'Asia/Shanghai',
    locale: 'zh-CN',
    use24Hour: true,
  }
});

// ========== 2. 从数据库获取订单数据 ==========
const orderData = {
  id: 'ORD-2024-001',
  createTime: 1705312800000,      // 数据库存的 UTC 时间戳
  deliveryTime: '14:30',          // 每天下午2点半配送
};

// ========== 3. 处理日期时间 ==========
// 创建日期对象
const createDate = DateTimeObj.fromUTCTimestamp(orderData.createTime);

// 显示在页面上
console.log(`订单号：${orderData.id}`);
console.log(`创建时间：${createDate.localDateTime}`);  // "2024-01-15 14:30:00"
console.log(`创建于：${createDate.rel.toString()}`);    // "3天前"

// ========== 4. 处理配送时间 ==========
const deliveryTime = TimeObj.fromString(orderData.deliveryTime);

// 判断配送时间是否已过
const now = DateTimeObj.now();
const todayDelivery = DateTimeObj.fromString(
  `${now.htmlDate} ${deliveryTime.localTime}`
);

if (todayDelivery.isBefore(now)) {
  console.log('今日配送已完成');
} else {
  console.log(`预计今日 ${deliveryTime.localTime} 配送`);
}

// ========== 5. 计算预计到达 ==========
const estimatedArrival = now.addDays(3);
console.log(`预计到达：${estimatedArrival.format('%Y年%m月%d日')}`);
```

### 5.常见错误 & 解决方法

|错误|原因|解决|
|---|---|---|
|`fromString` 返回 `null`|输入格式不对|检查输入字符串|
|时间显示不对|时区配置错误|检查 `initDateTimeConfig` 的 timezone|
|月份差1|JS 月份是0-11|不用管，库内部已处理|
|`GMT()` 结果不对|`sameTimeGlobally` 设置错|会议用 `true`，提醒用 `false`|
