# 01-库存管理模块

> #模块/核心 #状态/编写中

## 1. 模块概述

### 1.1 功能简介
库存管理模块负责对企业物料、商品的入库、出库、盘点、调拨等全过程进行管理，确保账实相符，为采购和销售提供准确的库存数据支撑。

### 1.2 业务价值
- **降低库存成本**：通过安全库存预警，避免过量采购和库存积压
- **提高周转效率**：实时掌握库存状态，加速库存周转
- **减少人工差错**：系统化管理替代手工台账，降低出错率

### 1.3 相关模块
- 上游模块：[[02-采购管理模块]]（采购入库）、销售管理模块（销售出库）
- 下游模块：财务管理模块（库存成本核算）、报表分析模块

## 2. 业务流程

### 2.1 入库流程

```mermaid
flowchart TD
    A[采购订单/生产完工] --> B{质检}
    B -->|合格| C[生成入库单]
    B -->|不合格| D[退货/返工]
    C --> E[更新库存数量]
    E --> F[更新库存金额]
    F --> G[入库完成]
    D --> H[结束]
```

### 2.2 出库流程

```mermaid
flowchart TD
    A[销售订单/领料申请] --> B[库存可用量检查]
    B -->|充足| C[生成出库单]
    B -->|不足| D[缺货预警]
    C --> E[扣减库存数量]
    E --> F[更新库存金额]
    F --> G[出库完成]
    D --> H[触发采购建议]
```

### 2.3 流程说明
1. **入库环节**：采购到货或生产完工后，需先质检，合格品才能入库
2. **出库环节**：根据业务单据自动扣减库存，支持先进先出、加权平均等计价方式
3. **盘点环节**：定期或临时盘点，系统生成盘盈盘亏单自动调整

## 4. 数据模型

### 4.1 实体关系图

```mermaid
erDiagram
    WAREHOUSE ||--o{ INVENTORY : contains
    WAREHOUSE ||--o{ STOCK_IN : receives
    WAREHOUSE ||--o{ STOCK_OUT : ships
    MATERIAL ||--o{ INVENTORY : tracked_as
    MATERIAL ||--o{ STOCK_IN : received
    MATERIAL ||--o{ STOCK_OUT : shipped
    BATCH ||--o{ INVENTORY : grouped_by

    WAREHOUSE {
        string id PK
        string code "仓库编码"
        string name "仓库名称"
        string location "所在位置"
    }

    MATERIAL {
        string id PK
        string code "物料编码"
        string name "物料名称"
        string spec "规格型号"
        string unit "计量单位"
    }

    INVENTORY {
        string id PK
        string warehouse_id FK
        string material_id FK
        string batch_id FK
        float qty "库存数量"
        float locked_qty "锁定数量"
        float available_qty "可用数量"
    }

    STOCK_IN {
        string id PK
        string warehouse_id FK
        string material_id FK
        float qty "入库数量"
        date in_date "入库日期"
        string source_type "来源类型"
    }

    STOCK_OUT {
        string id PK
        string warehouse_id FK
        string material_id FK
        float qty "出库数量"
        date out_date "出库日期"
        string purpose "用途"
    }

    BATCH {
        string id PK
        string batch_no "批次号"
        date produce_date "生产日期"
        date expire_date "有效期至"
    }
```

### 4.2 核心字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| warehouse_id | string | 是 | 仓库唯一标识 |
| material_id | string | 是 | 物料唯一标识 |
| batch_id | string | 否 | 批次号，用于批次管理 |
| qty | decimal | 是 | 库存数量 |
| locked_qty | decimal | 是 | 已锁定数量（待出库） |
| available_qty | decimal | 是 | 可用数量 = qty - locked_qty |

## 5. 接口设计

### 5.1 接口列表

| 接口地址 | 方法 | 说明 |
|----------|------|------|
| /api/inventory/query | GET | 查询库存明细 |
| /api/inventory/in | POST | 入库操作 |
| /api/inventory/out | POST | 出库操作 |
| /api/inventory/transfer | POST | 库存调拨 |
| /api/inventory/adjust | POST | 库存调整（盘点） |

### 5.2 入库接口时序图

```mermaid
sequenceDiagram
    participant U as 仓库管理员
    participant F as 前端页面
    participant API as 库存服务
    participant DB as 数据库
    participant MSG as 消息队列

    U->>F: 扫描到货单，确认入库
    F->>API: POST /api/inventory/in
    API->>DB: 开启事务
    API->>DB: 插入入库单记录
    API->>DB: 更新库存数量
    API->>DB: 更新库存金额
    DB-->>API: 更新成功
    API->>MSG: 发送库存变更事件
    API->>DB: 提交事务
    API-->>F: 返回入库结果
    F-->>U: 显示入库成功
    MSG->>MSG: 触发下游（财务核算）
```
