# 02-采购管理模块

> #模块/核心 #状态/编写中

## 1. 模块概述

### 1.1 功能简介
采购管理模块覆盖从采购申请、询价比价、采购订单、到货质检到入库结算的全过程，帮助企业优化采购流程、控制采购成本。

### 1.2 业务价值
- **成本控制**：通过供应商比价、历史价格分析，降低采购成本
- **效率提升**：电子化审批流程，缩短采购周期
- **合规管理**：全流程留痕，满足审计要求

### 1.3 相关模块
- 上游模块：库存管理模块（库存预警触发采购）、需求计划模块
- 下游模块：[[01-库存管理模块]]（采购入库）、财务管理模块（应付账款）

## 2. 业务流程

### 2.1 采购全流程

```mermaid
flowchart LR
    A[采购申请] --> B[审批]
    B -->|通过| C[询价比价]
    B -->|驳回| A
    C --> D[选定供应商]
    D --> E[生成采购订单]
    E --> F[供应商确认]
    F --> G[到货通知]
    G --> H[质检]
    H -->|合格| I[入库]
    H -->|不合格| J[退货]
    I --> K[对账结算]
    J --> L[结束]
    K --> M[付款]
```

### 2.2 采购订单状态流转

```mermaid
stateDiagram-v2
    [*] --> 草稿
    草稿 --> 待审批 : 提交
    待审批 --> 已驳回 : 驳回
    已驳回 --> 草稿 : 修改后重新提交
    待审批 --> 待确认 : 审批通过
    待确认 --> 已确认 : 供应商确认
    已确认 --> 部分到货 : 分批到货
    已确认 --> 全部到货 : 全部到货
    部分到货 --> 全部到货 : 剩余到货
    全部到货 --> 已结案 : 对账完成
    已结案 --> [*]
```

### 2.3 流程说明
1. **采购申请**：由库存预警或手动发起，明确物料、数量、需求日期
2. **询价比价**：向多个供应商询价，系统记录报价供比对
3. **订单跟踪**：实时跟踪订单状态，预警到货延期风险
4. **质检入库**：货到后质检合格方可入库，不合格触发退货流程

## 4. 数据模型

### 4.1 实体关系图

```mermaid
erDiagram
    SUPPLIER ||--o{ PURCHASE_ORDER : provides
    PURCHASE_ORDER ||--|{ PO_LINE : contains
    PO_LINE ||--|| MATERIAL : requests
    PURCHASE_ORDER ||--o{ GOODS_RECEIPT : receives
    GOODS_RECEIPT ||--|{ GR_LINE : contains

    SUPPLIER {
        string id PK
        string code "供应商编码"
        string name "供应商名称"
        string category "分类"
        int rating "评级"
    }

    PURCHASE_ORDER {
        string id PK
        string supplier_id FK
        string po_no "采购订单号"
        date order_date "下单日期"
        date delivery_date "交货日期"
        string status "订单状态"
        float total_amount "订单总金额"
    }

    PO_LINE {
        string id PK
        string po_id FK
        string material_id FK
        float qty "采购数量"
        float price "单价"
        float line_amount "行金额"
    }

    GOODS_RECEIPT {
        string id PK
        string po_id FK
        string gr_no "收货单号"
        date receipt_date "收货日期"
        string inspector "质检员"
    }

    GR_LINE {
        string id PK
        string gr_id FK
        string po_line_id FK
        float qty "实收数量"
        float qualified_qty "合格数量"
        float reject_qty "拒收数量"
    }

    MATERIAL {
        string id PK
        string code "物料编码"
        string name "物料名称"
    }
```

## 5. 接口设计

### 5.1 采购下单时序图

```mermaid
sequenceDiagram
    participant U as 采购员
    participant F as 前端
    participant PO as 采购服务
    participant INV as 库存服务
    participant DB as 数据库

    U->>F: 填写采购申请
    F->>PO: POST /api/purchase/apply
    PO->>DB: 保存申请单
    PO-->>F: 返回申请单号
    F-->>U: 显示提交成功

    U->>F: 审批通过，生成订单
    F->>PO: POST /api/purchase/order
    PO->>DB: 开启事务
    PO->>DB: 生成采购订单
    PO->>DB: 生成订单明细
    PO->>INV: 预占库存通知
    PO->>DB: 提交事务
    PO-->>F: 返回订单信息
    F-->>U: 显示订单创建成功
```
