## 📝 新建模块

1. 复制 [`../../templates/模块说明模板.md`](../../templates/模块说明模板.md)
2. 命名为 `XX-模块名称.md` 放入此目录
3. 填写内容（可用 Kimi Code 辅助生成）
4. 更新上表

## 🏷️ 标签索引

在 Obsidian 中可使用以下标签快速筛选：

- `#模块/核心` — 核心业务流程模块
- `#模块/支撑` — 支撑类模块（如用户管理、权限管理）
- `#状态/已完成` — 已完成的模块文档
- `#状态/编写中` — 正在编写的模块文档
