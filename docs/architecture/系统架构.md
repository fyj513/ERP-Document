# 系统架构

本文档描述 ERP 系统的整体架构设计。

## 1. 系统全景图

```mermaid
flowchart TB
    subgraph 用户层
        Web[Web 浏览器]
        Mobile[移动端 App]
        Mini[小程序]
    end

    subgraph 接入层
        CDN[CDN 加速]
        GW[API 网关]
        LB[负载均衡]
    end

    subgraph 应用层
        Auth[认证中心]
        User[用户服务]
        INV[[库存服务]]
        PUR[[采购服务]]
        Sale[销售服务]
        Fin[财务服务]
        Report[报表服务]
    end

    subgraph 数据层
        MySQL[(MySQL<br/>业务数据)]
        Redis[(Redis<br/>缓存)]
        ES[(ES<br/>搜索)]
        MinIO[(MinIO<br/>文件存储)]
        MQ[(RabbitMQ<br/>消息队列)]
    end

    Web --> CDN --> GW
    Mobile --> LB --> GW
    Mini --> GW
    GW --> Auth
    GW --> User
    GW --> INV
    GW --> PUR
    GW --> Sale
    GW --> Fin
    GW --> Report

    INV --> MySQL
    INV --> Redis
    PUR --> MySQL
    PUR --> MQ
    Sale --> MySQL
    Fin --> MySQL
    Report --> ES
    Auth --> Redis
    User --> MySQL
```

## 2. 模块依赖关系

```mermaid
flowchart LR

    采购 -->|应付| 财务
    销售 -->|应收| 财务

```

## 3. 技术栈规划

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Vue 3 / Element Plus | PC 管理端 |
| 移动端 | UniApp | 跨平台 App/小程序 |
| 后端 | Spring Boot | Java 微服务 |
| 数据库 | MySQL 8.0 | 主数据库 |
| 缓存 | Redis | 热点数据、会话缓存 |
| 搜索 | Elasticsearch | 商品搜索、日志检索 |
| 消息队列 | RabbitMQ | 异步解耦、事件驱动 |
| 文件存储 | MinIO | 文档、图片存储 |
| 容器化 | Docker + K8s | 部署运维 |

## 4. 部署架构（规划）

```mermaid
flowchart LR
    subgraph 生产环境
        N1[Nginx 1]
        N2[Nginx 2]
        App1[App 节点 1]

    end

    User[用户] --> N1
    User --> N2
    N1 --> App1
    N1 --> App2
    N2 --> App2
    N2 --> App3
    App1 --> DB1
    App2 --> DB1
    App3 --> DB1
    DB1 -.-> DB2
    App1 --> R1
    App2 --> R1
    R1 -.-> R2
```
