# 文档中心

欢迎进入 ERP 文档中心！本文档使用 **Markdown** 编写，支持在 Obsidian 和 VS Code 中无缝阅读。

## 📂 目录结构

```
docs/
├── modules/          ← 业务模块说明（核心文档）
├── architecture/     ← 系统架构与技术方案
└── guides/           ← 操作指南与规范
```

## 🔗 常用链接

- [模块列表](modules/README.md)
- [系统架构](architecture/系统架构.md)
- [文档模板](../templates/模块说明模板.md)

## 💡 提示

- 在 **Obsidian** 中使用 `[[` 可快速创建双链，如 `[[库存管理模块]]`
- 在 **VS Code** 中使用 `Ctrl+Shift+P` → `Markdown: 打开预览` 查看渲染效果
- 所有 Mermaid 图表在两个工具中都能正常显示
