
准备提交合并之前要检查两件事情

1.你是否已经把所有的注释还有代码中的中文全部翻译成英文了？

2.你是否已经pull了最新的代码了？


如果你在提交pull request之前发现有新的commit被push到远程仓库，你需要先pull最新的代码，解决冲突后再push你的代码。这样可以确保你的pull request是基于最新的代码，并且不会引入冲突。

如果你在pull最新的代码时遇到了冲突，需要手动解决冲突后再commit并push你的代码。解决冲突后，记得在commit message中注明解决了哪些冲突，以便其他人了解你的修改内容。
总之，在提交pull request之前，确保你的代码是最新的，并且没有冲突。

如果你已经提交了pull request，但后来发现有新的commit被push到远程仓库，你可以在pull request页面上点击"Update branch"按钮来更新你的分支。这样会将最新的代码合并到你的分支中，并且会自动解决一些简单的冲突。如果有复杂的冲突需要手动解决，你可以在本地pull最新的代码，解决冲突后再push你的代码。更新分支后，pull request会自动更新，并且会显示最新的代码和解决冲突的情况。这样可以确保你的pull request是基于最新的代码，并且不会引入冲突。
