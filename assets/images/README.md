# 图片资源目录

本目录存放 PNG、JPG、GIF 等**静态图片文件**。

## 📂 用途

- 页面原型截图（UI 设计图）
- 业务流程截图（系统操作截图）
- 架构设计图（非 Mermaid 的专业设计工具导出图）
- 照片、Logo 等素材

## 📝 命名规范

请使用以下格式命名图片文件：

```
{模块名}-{用途}-{日期}.{扩展名}
```

示例：

| 文件名 | 说明 |
|--------|------|
| `库存管理-查询页面-20250427.png` | 库存管理模块的查询页面原型 |
| `采购管理-流程图-20250427.jpg` | 采购管理模块的流程图 |
| `系统架构-部署图-20250427.png` | 系统部署架构图 |

## ⚠️ 注意事项

1. **不要直接粘贴超大图片**（> 2MB），请先用工具压缩
2. **不要存放临时截图**，用完即删或移到归档目录
3. **敏感信息打码**：截图中包含真实数据时，请模糊处理敏感信息
4. **优先使用 Mermaid**：能用代码表达的图表，不要存为图片（放在 `assets/diagrams/` 或直接用 Mermaid 代码块）
